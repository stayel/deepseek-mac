# DeepSeek 本地 Agent 使用与安全须知（Windows 版）

> 配套产物：`windows\publish\DeepSeek.exe`（已构建，退出码 0，PE 有效）
> 适用场景：用 **DeepSeek 免费网页端**当"大脑"，在**你本机 PowerShell** 上自动执行命令、读写文件。
> 注意：这是 **DeepSeek**，不是 ChatGPT。

---

## 一、它到底能干什么
- ✅ 在你机器上**真实运行 PowerShell** 命令（不是云端沙箱）。
- ✅ **读取**本地文件（`Get-Content`、`dir` 等命令在本地执行）。
- ✅ **创建/修改**本地文件（`write_file:路径` 代码块直接落盘，或让它输出 `Set-Content` / `Out-File`）。
- ✅ 跑 Git、编译、测试等系统命令。
- ✅ **零 API 费用**：吃 DeepSeek 免费网页额度。

## 二、第一次怎么用
1. 双击 `windows\publish\DeepSeek.exe`。
2. 应用内 WebView 会打开 DeepSeek 网页 → 登录你的 **DeepSeek 免费账号**。
3. 按 **Ctrl + I**（或点右上角"⚡️ 注入大脑协议"）注入 Agent 协议。
4. 用中文/英文下任务，例如："分析当前目录的代码文件并写个自动化测试脚本"。
5. 应用会自动捕获 DeepSeek 输出的代码块 → 本地 PowerShell 执行 → 结果回填聊天 → DeepSeek 继续下一步。
6. 不放心时，点 HUD 上的"**自动闭环: 开/暂停**"暂停自动执行。

## 三、工作原理（白话）
- **大脑**：DeepSeek 网页端规划、分步、写代码。
- **执行者**：应用捕获代码块，用 `powershell.exe -EncodedCommand`（Base64 编码，避免引号/换行转义失效）在本地执行。
- **落盘**：以 `write_file:路径` 开头的代码块，由 C# 宿主直接原子写入磁盘（自动建多级目录）。
- **附件/截图**：`agent-screenshot` 截屏回传、`agent-attach` 大文件挂载，长输出自动折叠。

## 四、⚠️ 安全须知（务必先读）
> 这个工具会**自动执行 AI 生成的 PowerShell**，权限比"先把命令给你确认"的方案更高。请遵守以下规则：

1. **目录隔离**：只在**专用空目录**（如 `D:\MCP-Test`）里开启自动闭环；**绝不在** `C:\`、`C:\Users`、桌面、下载等有重要数据的目录跑来路不明的指令。
2. **先干跑再执行**：复杂/危险任务，先让它"只输出命令、不执行"，你确认无误后再放行。
3. **善用暂停**：HUD 的"自动闭环: 暂停"随时可停；怀疑时立刻暂停。
4. **`write_file:` 会直接覆盖/创建文件**：确认路径正确，别指向重要文件。
5. **免费额度限流**：DeepSeek 网页可能限流，应用已内置"人类化 pacing（Anti-Ban）"缓解，但别高频轰炸。
6. **联网前提**：需联网访问 DeepSeek 网页；本地执行本身离线。
7. **信任边界**：只连你信任的来源。它执行的命令来自 AI 输出，存在被"提示注入"误导的风险——对"删除/格式化/外发数据"类指令保持警惕。

跑通这个，再逐步放开到真实的读/写/命令任务。

## 六、排错
| 现象 | 处理 |
|------|------|
| 启动报缺 .NET | 安装 [.NET 8 运行时/SDK](https://dotnet.microsoft.com/download/dotnet/8.0) |
| 白屏 / 网页打不开 | 确认 WebView2 Runtime 已装（Win11 默认自带；Win10 旧版需手动装） |
| 登录不了 | 先在系统浏览器登录 DeepSeek，再在应用内刷新（Ctrl+R） |
| 命令不执行 / 超时 | 单条命令上限 180 秒，超时自动中断；先确认本机 `powershell.exe` 可用 |
| 频繁限流暂停 | 属正常现象（Anti-Ban）；可开新会话或稍后再试 |
